# 🎡 Imagineers Conference EXPO25

A responsive event landing page designed to promote a fictional engineering and innovation conference inspired by the world of Imagineering. The project focuses on creating an engaging user experience through interactive web design, accessibility features, dynamic form handling, and modern front-end development practices.

## 🚀 Project Overview

Imagineers Conference EXPO25 is a multi-section event website that introduces attendees to a conference centered around creativity, engineering, innovation, and experiential design.

The site provides information about the event, schedules, registration, featured activities, and external learning resources while incorporating interactive functionality to improve user engagement.

## ✨ Features

### Navigation & User Experience

* Sticky navigation bar with anchor links
* Smooth section navigation
* Responsive page layout
* Embedded promotional video

### Accessibility Features

* Dark Mode toggle
* Reduce Motion toggle for animation-sensitive users
* Semantic HTML structure
* Form labels and accessibility-friendly inputs

### Interactive RSVP System

* User registration form
* Form validation
* Dynamic RSVP participant count
* Real-time participant list updates
* Success confirmation modal

### Dynamic User Feedback

* Personalized confirmation messages
* Modal popup interactions
* Event participation tracking

### Event Content Sections

* Event overview and mission
* Conference schedule
* Featured activities
* Educational resources and external links
